# Folio

写真から思い出の冊子をつくる、端末内で完結するWebアプリです。
React 19 / TypeScript / Vite（Vinextの静的書き出し）を使用しています。アプリのバックエンド、外部SDK、広告、写真のアップロード先はありません。

## 起動

Node.js 22.13以上とpnpmを使用します。

```sh
pnpm install
pnpm dev
```

表示されたローカルURLを開いてください。公開用ファイルは `pnpm build` で `dist/client/` に生成されます。このフォルダを静的サーバーで配信できます。HTTPSまたはlocalhostが必要です。

`main` ブランチをGitHubへ送ると、同梱のGitHub ActionsがGitHub Pagesへ公開します。リポジトリのPages設定でSourceを「GitHub Actions」にしてください。公開されるのはアプリ本体とサンプルだけで、IndexedDBに保存した利用者の写真や冊子はリポジトリにもビルドにも含まれません。

## できること

- 冊子の作成・閲覧・編集・削除。表紙を含め最大15ページ。
- 8テーマ、10種類の紙。紙色・線・濃さ・質感をページごとに調整。
- 1ページ最大5枚の写真。縦横比を考慮したシード付き自動配置と再生成。
- 写真・テキスト・10種類の装飾を移動、サイズ変更、回転、複製、ロック、重なり順変更。
- ペン、マーカー、点線、消しゴムによるページ全体への落書き。色、太さ、表示切替。
- 編集の元に戻す・やり直す（編集中の直近40操作）。矢印キーで選択要素を移動。
- 本型／バインダー型、横スワイプ・矢印キー・ボタンによる3Dページ送り。
- スマートフォンは1ページ、PC・横画面は見開き。
- 写真とサムネイルをBlobとしてIndexedDB保存。本文・落書きもIndexedDBへ自動保存。
- 初回読み込み後、Service Workerのキャッシュが完了するとオフラインでも再度開けます。

## 保存の注意

保存先は同じブラウザ・同じサイトのIndexedDBです。別の端末や別URLには同期されません。ブラウザのサイトデータを消すと冊子も失われます。プライベートブラウズや空き容量不足では保存できないことがあります。保存に失敗した場合は変更を画面上に残し、再保存できます。写真の原本は別途保管してください。

写真は端末内で長辺2200pxまで縮小し、一覧向け420pxサムネイルも作ります。1枚35MBまで。対応形式は利用ブラウザで読み込めるJPEG、PNG、WebP等です。HEICの対応状況はブラウザ依存です。

## 構成

- `lib/folio/model.ts`: 冊子・ページ・要素の型、テーマと紙の定義。
- `lib/folio/layout.ts`: シード付き制約レイアウト。
- `lib/folio/storage.ts`: IndexedDBトランザクション、Blob処理。
- `components/folio/PageCanvas.tsx`: 共通ページ描画とポインター操作、落書き。
- `components/folio/Editor.tsx`: 編集、ページ操作、履歴。
- `components/folio/Reader.tsx`: 見開きと3Dページ送り。
- `components/folio/CreateDialog.tsx`: 新規冊子作成。
- `scripts/offline.mjs`: 静的出力のオフラインキャッシュ生成。

IndexedDBのストアは `folios` / `pages` / `photos`。新規画像・ページ・冊子は同一トランザクションで保存します。履歴は端末のメモリ上に保持し、ページ更新で消えます。写真削除の取り消しに備え、未参照のBlobは冊子削除時に回収します。

## 検証

```sh
pnpm test
pnpm typecheck
pnpm build
```

テストでは8テーマ×写真1〜5枚×40シードの1,600通りを検証し、配置の再現性・変化・境界・縦横比・ロックを確認します。IndexedDBの写真Blobと落書きの復元、失敗時ロールバック、ページ削除、共有画像参照の保持も検証します。iPhone実機・ブラウザ操作の自動テストは含みません。

## 初期版の範囲

顔認識・自動トリミングは行わず、写真全体を表示することを基本にしています。ページめくりはCSS 3Dによる演出です。クラウド同期、PDF出力、旅行しおりは含みません。画像・冊子データを送信する機能はありません。

サンプル写真の撮影者とライセンスは `public/samples/ATTRIBUTION.md` に記載しています。サンプルを編集すると、自分の冊子としてコピーされます。

## UI刷新版

作成は「写真を1〜5枚選ぶ → ミニページでテーマを選ぶ → 大きな自動生成結果 → 自分でアレンジ」の3ステップです。タイトルの入力は不要で、作成後に冊子の設定から変更できます。

スマートフォンは紙が中央に大きく置かれる編集画面と、写真・文字・ステッカー・ペン・紙・テーマの下部ツールバー。各ツールはボトムシートで開きます。PCはページ一覧、見開き、選択した要素の設定を並べます。ページ一覧のドラッグ、またはシート内の矢印で順序を変えられます（表紙は先頭固定）。

自動配置は写真の主役・構図・余白・装飾・おすすめの紙を変化させます。全面写真を使う構図では中央でトリミングします。「写真全体」へ戻すこともできます。自動生成した装飾も編集すると手動要素として保存され、以後の再生成時に保持されます。ロックした要素も維持します。

ページめくりは連続する7つの面からなる紙の曲面を描画します。指・マウスの横移動に追従し、裏面、持ち上がった縁、移動する影を表示します。短いドラッグは元のページへ戻ります。視差を減らす設定にも対応します。

IndexedDBのデータベース名と3ストアは変更していません。既存の冊子データは移行なしでそのまま開けます。Yomogiの手書きフォントもローカルに同梱しています（ライセンス: `public/fonts/OFL.txt`）。
