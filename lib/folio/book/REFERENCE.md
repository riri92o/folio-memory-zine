# Folio Book

閉じた表紙から始まり、画面上でめくれる本の部品です。追加ライブラリ・外部通信なしで動作します。

## すぐ試す

`folio-book-demo.html` をブラウザで開いてください。この1ファイルだけで動きます。

- 表紙をドラッグ／クリックすると開きます。最初の見開きから前へ戻すと閉じます。表紙のタイトルは本文1ページ目の `title` を使用します。
- 左右のページをドラッグ／スワイプすると、指に合わせて紙が持ち上がります。
- 途中で離すと、位置・速度に応じて最後までめくるか元へ戻ります。
- ページのクリック、下の矢印ボタン、キーボードの左右キーでも操作できます。
- OSの「視差効果を減らす」設定では、自動めくりのアニメーションを省略します。

## Folioへの組み込み

`folio-book.js` を配置して、以下を追加します。ビルド作業は不要です。

```html
<div style="height: min(800px, 90svh); background: #152b25;">
  <folio-book id="reader"></folio-book>
</div>
<script src="./folio-book.js"></script>
```

Web Component / Shadow DOMでスタイルを分離しています。Reactなどではクライアント側でスクリプトを読み込み、`folio-book` 要素を配置してください。SSR中にJSファイルを直接評価しないでください。アプリのCSP設定により、スクリプト・コンポーネント内styleの許可が必要な場合があります。

## 内容を差し替える

スクリプト読み込み後、`pages` プロパティに配列を設定します。左、右の順です。2ページ以上が必要で、奇数の場合は最後に空白を追加します。

```js
const book = document.querySelector('folio-book');
book.pages = [
  { eyebrow: 'FOLIO / 01', title: '本の\nタイトル',
    body: '本文の一行目。\n本文の二行目。',
    color: '#f4f0e6', ink: '#263d3b', kind: 'title' },
  { title: 'はじめに', body: 'ここに本文を入れます。' },
  { image: './pages/03.jpg', title: '第2章', body: '読み上げ用の説明' },
  { image: './pages/04.jpg', title: '第2章の続き', body: '読み上げ用の説明' }
];
```

- 画像は縦横比 **5:7（例：1000×1400px）** を推奨。ページ内に全体が収まるよう配置します。
- 本番の自由なレイアウトは、デザイン済みのページ画像を指定すると管理しやすくなります。
- 別ドメインの画像は配信元のCORS許可が必要です。原則、アプリと同じ場所に配置してください。
- テキストモードは見本用の固定組版です。タイトルは2行、本文は7行程度が目安です。長文はページに分割するか、画像として組版してください。
- `pages` を変更すると閉じた表紙へ戻ります。

## 外部から操作する

```js
book.nextPage();        // 次の見開き。開始できた場合 true
book.previousPage();    // 前の見開き
book.currentSpread;     // 表紙は -1、本文は0始まりの見開き番号
book.addEventListener('pagechange', e => console.log(e.detail));
// { spread: 1, pages: [3, 4], cover: false }
// 表紙に閉じた場合: { spread: -1, pages: [], cover: true }
book.addEventListener('pageerror', e => console.log(e.detail));
// 読み込めなかった画像の { index, src }
```

## 実装と運用上の範囲

ページを56分割し、三次元座標からCanvasへ投影しています。紙のしなり、表裏、綴じ目の陰影、紙の厚みを表現しています。物理シミュレーションや汎用3Dモデルではありません。PDFの直接読み込み・編集・サーバー保存機能は含みません。

Canvas表示のため本文の選択・検索はできません。見開きのタイトルと本文はスクリーンリーダー用にも出力します。写真ページにも説明を設定してください。

主要な現行ブラウザ向けの実装です。組み込むFolioの実環境では、タッチ操作・表示サイズ・性能をご確認ください。ページ画像はすべてメモリに展開されるため、大量のページには遅延読み込みへの拡張が必要です。
